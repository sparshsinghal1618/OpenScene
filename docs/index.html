Everything in the box

A real editor, not a demo

Every part is written from scratch and runs on the web engine that already ships with Windows.

◆

Multi-track timeline

Unlimited video and audio tracks, open-ended length, razor, ripple, roll, slip, snapping, groups, markers and a scrollable overview. Drag files in and they land end-to-end on one row.

◐

164 transitions

Dissolves, slides, pushes, wipes, shapes, reveals, blurs, warps and more. Every transition is exact at both ends — frame 0 is pure A, the last frame is pure B, with no transparency holes.

✦

136 effects

Colour, curves, LUTs, blur, sharpen, glow, keying, masking, distortion, time, stylise and audio. Stack them, reorder them, and keyframe any control.

⌘

Keyframes & curves

Keyframe position, scale, rotation, opacity, crop, volume, EQ and every effect parameter. Linear, eased and hold interpolation, drag-and-drop on the timeline.

T

Titling

Text, lower-thirds, callouts and credits with fonts, fills, outlines, shadows and animation presets — rendered by the same compositor as everything else.

♫

Audio mastering bus

Per-clip volume, fades, EQ and pan, plus a master bus with a limiter and metering. Waveforms are drawn from real decoded peaks.

▶

Frame-exact export

An H.264/AAC MP4 muxer (ISO-BMFF) written in the project. Render at full quality, with hardware encoding when the GPU offers it and a clean software fallback.

⇄

OpenShot projects open

Drop a .osp file in and OpenScene converts its layers, clips, keyframes, blend modes and filters into an editable project on the spot.

◉

Offline by design

Media is read from your disk, decoded in-process and stored locally. Projects reopen instantly. Nothing is uploaded, ever.

Questions

Frequently asked

Is it really free?

Yes. OpenScene is released under the MIT licence. Use it commercially, modify it, ship it — no cost and no permission needed.

Does anything leave my computer?

No. OpenScene never makes a network request. Media is read from your disk, decoded in-process, and stored locally so projects reopen instantly.

What is a .oscene file?

It is OpenScene's own project format — plain JSON, so it is inspectable and diff-friendly. Older .osceneproj files still open.

Can it open OpenShot projects?

Yes. Open a .osp file and OpenScene converts its layers, clips, keyframes, blend modes and filters into an editable project. Anything it cannot map is counted and reported rather than silently dropped.

What formats can I import?

Every container and codec the underlying web engine can decode — 221 extensions across video, audio and images, with a clear message when a codec is genuinely unsupported. Just drop files onto the window.

Why is there no macOS, Linux or mobile build yet?

The editor engine is written to be platform-neutral and already runs in a plain browser tab. Those targets need their own thin native shells and, for the mobile stores, signing and store review. They are marked coming soon on this page.

How do I know it actually works?

It ships with an end-to-end acceptance suite that exercises the model, the compositor, the exporter, the muxer and the project formats. It currently reports 81 passed, 0 failed — you can run it from the Help menu.
